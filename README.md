**E-GAS Distribution Service** is a full‑stack web application designed to streamline gas distribution services including order management, delivery tracking, and customer management. Built using the **MERN stack** with a clean and responsive interface.

---

## 📖 Overview

A web‑based gas distribution service platform designed to digitize and simplify the entire gas ordering and delivery process – from customer registration and order placement to real‑time delivery tracking.

## 🛠 Technologies Used

- **MongoDB** – NoSQL database
- **Express.js** – backend framework
- **React.js** – frontend library
- **Node.js** – runtime environment
- **JavaScript** – core language
- **CSS3 / HTML5** – styling and markup

## ✨ Key Features

- 👤 Customer registration and profile management
- 🛒 Gas order placement and tracking (status: pending, confirmed, out for delivery, delivered)
- 🚚 Delivery management system (assign delivery personnel, update status)
- 📊 Admin dashboard with order analytics and inventory overview
- 🔍 Search and filter functionality (orders, customers, deliveries)
- 📱 Responsive design for all devices (mobile, tablet, desktop)
- 🔔 Real‑time order status updates (via polling or WebSocket)
